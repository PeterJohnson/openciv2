Original artwork is not yet a runtime match

The standalone review executes selected source draw routines, then supplies text, panels and parts of the scene through adapters. Comparing the original-art scenes to actual runtime screenshots confirms differences beyond font choice.

References below are existing native OpenCiv2 screenshots from the repository, not fresh captures of the installed original executable. Saves, era, viewport and scale are not aligned. This is a visual/source audit; no pixel-parity score is claimed. The live original-game launch hit an app-approval timeout.

    The font difference is measurable

    The source diplomacy font is face 0 (Times New Roman), height 11. Its 13-pixel cell and 10-pixel ascent come from the reference font bank. The review instead substitutes SVG text and bypasses the source wrapping. Map text also estimates every character at six pixels at 1×.

    Metrics from the port’s Wine-reference bitmap bank, not a fresh Windows GDI measurement. Map-shim values illustrate its fixed-width approximation; they are not the diplomacy SVG renderer’s measured output. Widths are pixels, not a pixel-diff result. Even selecting the same family name is insufficient without the matching font data, baseline, clipping, shadow, palette and antialiasing path.

    What is not visually verified yet

    Spacecraft and throne-room scenes have source-trace checks but no matching runtime screenshot here. Spacecraft text, statistics and controls remain adapters. A clean Debug/Release trace comparison proves repeatability of the standalone harness, not equality to the game's finished framebuffer.

    Order of repair

    1. Lock one save/state, era, viewport, zoom, platform/font environment and capture frame. Capture the same content rectangle in the real game and standalone review.
    2. Carry font face, height, weight, palette colors, alignment and clip rectangles through the trace. Reuse the target repository's text backend and its measured/drawing advances; remove eight-character truncation and execute the source wrapping path with its caller state.
    3. Restore source city economy panels, controls and resource-map drawing. Add the missing map names and panorama title. Separate intentionally static diplomacy from herald/video parity.
    4. Compare dimensions and exact pixels for matching cases, saving difference images and mismatched bounding boxes. Keep HD and enhancement variants separate from this native acceptance gate.

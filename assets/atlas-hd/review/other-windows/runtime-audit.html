Standalone renderer vs actual game execution

Four-way window gallery · Extraction and boundaries · Capture provenance and source identity

These are actual OpenCiv2 execution captures using the original game artwork, build bd89036fc339, and the same 1788 saved game. They are not captures of the legacy 1999 executable. All 21 recorded source/font inputs match this review extraction after line-ending normalization.

The 35 baseline scenes now use extracted game rendering code. Twelve are visually compared here. Original, native replacement and HD share each scene’s commands; enhanced proposals remain separate. Source geometry includes its existing clipping and crowded labels. Cursor/focus effects, capture scaling, differing auxiliary-panel sizes and the runtime extras option remain explicit differences; this is not a claim of pixel identity.

The comparison corrected sprite-size queries, missing popup artwork, native control/theme rasterization, label-table blank-line handling and saved-unit glyph state. Tax totals now execute the game calculation. Raw captures are preserved; only the overlay view rescales crops for alignment.
